# Limitations

- This benchmark measures Korean multi-turn context translation, not general translation quality.
- Result sets use automated judge models. Automated judging can reflect model bias; the 2026-08 Live experiment and the 2026-08 issue-1 experiment judged with `gemini-3.7-flash:batch`, the 2026-04 experiment with `gemini-3.1-pro-preview`.
- The 2026-08 Live run reports `benchmarkValid: false`: 12 unresolved translation failures (8 Gemini Live session timeouts on 2 samples across all 3 target languages, plus 4 historical DeepL failures carried over from the forked run) and 19 judge failures (17 carried over on Gemma 4 E4B QAT Q2 en/ja, 2 on new Live cells). Per-system scored sample counts differ (631–648). The common-cell ordering matches the full ordering.
- The 2026-08 Live run is a fork-and-merge continuation: 7,124 of 7,764 translation cells were reused from the 2026-08 issue-1 run; only the 640 Gemini 3.5 Live Translate cells are new. All cells were judged under one judge setup, but the reused translations were produced across multiple sessions and runs.
- The audio-native Live arm depends on TTS and ASR: the Korean source is spoken by a local two-voice TTS pipeline, and the Live session's streaming transcription is the input to translation. The ASR CER analysis (`experiments/2026-08-gemini35-live-two-voice/reports/ASR-CER-analysis.md`) is a standalone unofficial analysis of `input_transcription_events`, not part of the runner's report pipeline. CER is measured against the intended transcript (not the audio), 3.1% of Live sessions carry a wrong `languageCode` label (Korean audio labeled `ja`/`en`, sometimes with a genuinely Japanese transcription), and the strict CER mean (0.112) is above a 5% band — do not cite the Live run as a clean-ASR result without these caveats.
- Experiments differ in translation prompt, judge model, and judge prompt format. Scores are comparable only within one experiment; do not mix scores across experiments, and do not treat fork-reused rows as fresh measurements.
- The dataset intentionally stresses context use and context rejection. It is not a random sample of all translation tasks.
- Commercial service rows (Papago, DeepL, Google) are context-blind baselines in this setup unless explicitly marked otherwise.
- Model APIs, model versions, availability, latency, and prices can drift over time.
- Local llama.cpp results depend on quantization file, server version, and sampling settings; the 2026-08 issue-1 local arms used the configurations recorded in `experiments/2026-08-…-archived/manifest.json`.
- TTS output and Live session behavior (voice identity, session timeouts, streaming transcription) can vary across runs; the audio provenance recorded in `experiments/2026-08-gemini35-live-two-voice/audio-assets/manifest.json` pins the model files, voices, and runtime used.
- Exact reruns may not reproduce identical scores because provider model behavior and automated judge behavior can drift.
- Full reproduction requires paid provider APIs, credentials, local GPU servers, a local TTS pipeline, and judge access.
